# 民数记略

宁波土话，1895 年版。

书影来自 [哈佛大学燕京图书馆](https://id.lib.harvard.edu/alma/990081283790203941/catalog)。

人名、地名转写参照官话和合本、上海土白圣经、苏州土白圣经的译名。转写的文本中使用专名号（下划线）标注了所有的人名、地名。由于 Github 网页不支持显示 Markdown 文件的下划线。因此，在网页端查看 Markdown 文件时无法看到专名号。想要完整看到带人名、地名标注的转写，请下载 Markdown 文件，并使用支持 Markdown 文件 html 语法的软件打开。

本书似缺乏仔细校对，存在人名、地名写法前后不一的问题。本书还存在大量 eh、ah 混拼的情况，另有少量尖团不分的情况。相较而言，1899 版《创世记》、1899 版《出埃及记》等同时代文献可能经过更仔细的校对，极少有 eh、ah 不分、尖团不分的情形。因此本书更能反应 19 世纪末宁波府城音系相较 19 世纪中叶的演变。

在翻译用词方面，本书较同时代文献含有更多的官话成分。例如，多用「dzæ（在）」却少用「læ（来）」，常用「djü（住）」表示居住等。
